# **Clasificación automática de tipos de acné facial**

![banner](https://drive.google.com/uc?export=view&id=1xXc0BMeni7py5uOj7yasuk6DI-aFd3Bq)


## **Autores**
Andrés Rodríguez, Adrián Bernal y Héctor Franco.

## **Objetivos**
Implementar distintos modelos de aprendizaje supervisado y no supervisado para la clasificación automática de tipos de acné facial.

## **Dataset**
* [Acne Dataset Image](https://www.kaggle.com/datasets/tiswan14/acne-dataset-image)

## **Modelos**
* GAUSSIAN NAIVE BAYES
* Decision Three
* Random Forest
* SUPER VECTOR MACHINE
* Red Neuronal Convolucional
